# Shoe Configurator

A futuristic 3D shoe configurator built with plain [three.js](https://threejs.org) and [Vite](https://vite.dev), built stage by stage while working through [Three.js Journey](https://threejs-journey.com).

## Run it

```bash
npm install
npm run dev
```

## Stages

- [x] **Stage 1** — Scene, camera, renderer, render loop, resizing
- [ ] **Stage 2** — Load a glTF shoe + OrbitControls
- [ ] **Stage 3** — Lighting, environment map, realistic render
- [ ] **Stage 4** — Raycasting: click to select shoe parts
- [ ] **Stage 5** — Colour picker UI + camera transitions
